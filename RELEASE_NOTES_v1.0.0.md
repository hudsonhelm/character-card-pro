# Chub PNG Character Card Editor v1.0.0

Initial public release.

- English-only Windows EXE.
- Opens chub.ai / SillyTavern PNG character cards using `chara` or `ccv3` metadata.
- Edits common card fields in separate text boxes.
- Supports UTF-8 card content.
- Saves in place or saves as a new PNG.
- Preserves unknown card fields and platform-specific extensions.
